Comience a usar NRV

Nice Return Visits (NRV) es una aplicación gratuita para organizar los datos de contactos y el historial de revisitas. Abra NRV para usarlo en el navegador o añada un icono de la aplicación a su dispositivo.

Abrir NRV

Elija cómo usar NRV

Navegador o icono de la aplicación

La primera vez que visite NRV en un navegador, se le preguntará si quiere configurar el icono de la aplicación o usar NRV en ese navegador.

Usar NRV en el navegador

Elija Use NRV in this browser (Usar NRV en este navegador) para continuar en una pestaña. Para volver a esta copia de trabajo, use el mismo navegador en el mismo dispositivo.

Añadir el icono de la aplicación NRV

Elija Set up the app icon (recommended) (Configurar el icono de la aplicación [recomendado]), siga las instrucciones para su dispositivo y luego abra NRV desde el nuevo icono. Al abrir la aplicación instalada, se omite la pantalla para elegir el navegador.

Tenga en cuenta que puede haber copias distintas. Cada navegador o aplicación instalada puede tener su propia copia local de los datos de NRV. Añadir un icono no transfiere los contactos de una copia del navegador. Si ya tiene contactos, haga una copia de seguridad de esa copia y restáurela en la nueva antes de cambiar. Compruebe los datos restaurados antes de borrar o eliminar los originales.

Instale el icono de la aplicación

Siga los pasos para su dispositivo

Primero, abra la página de la aplicación NRV. Las opciones y los nombres de instalación varían según el navegador, el dispositivo y la versión del software.

Elija su dispositivo

iPhone: Safari

  1. Abra la página de la aplicación NRV en Safari. Si se abrió dentro de otra aplicación, ábrala primero en Safari.
  2. Toque Más (tres puntos) cerca de la barra de direcciones y luego Compartir (el cuadrado con una flecha hacia arriba). Si Compartir ya está visible, tóquelo directamente.
  3. Desplácese hacia abajo y toque Añadir a pantalla de inicio. Si es necesario, use Editar acciones para añadirlo al menú Compartir.
  4. Active Abrir como aplicación web si aparece y luego toque Añadir.

Los controles de Safari pueden variar según la versión y la disposición de iOS. Consulte las instrucciones de Apple para iPhone. Para otro navegador, consulte su ayuda sobre cómo instalar un sitio web como aplicación.

iPad: Safari

  1. Abra la página de la aplicación NRV en Safari. Si se abrió dentro de otra aplicación, ábrala primero en Safari.
  2. Toque el botón Compartir de Safari (el cuadrado con una flecha hacia arriba).
  3. Toque Ver más y luego Añadir a pantalla de inicio. Es posible que deba desplazarse para encontrarlo.
  4. Active Abrir como aplicación web si aparece y luego toque Añadir.

Los controles pueden variar según la versión de iPadOS. Consulte las instrucciones de Apple para iPad. Para otro navegador, consulte su ayuda sobre cómo instalar un sitio web como aplicación.

Orientación para la instalación

Los pasos de instalación varían según el dispositivo y el navegador. Busque en el menú del navegador una opción como Instalar aplicación o Añadir a pantalla de inicio. Si no aparece, consulte la ayuda de su navegador sobre cómo instalar un sitio web como aplicación.

Primer uso

Configure su copia de trabajo

Después de elegir un navegador o abrir NRV desde el icono instalado, siga las instrucciones para empezar.

  1. Revise los acuerdos de la aplicación

    Antes de usar una copia del navegador o de la aplicación instalada, revise y acepte los Términos de uso y el Aviso de privacidad y datos vigentes. El acuerdo se muestra en cada copia hasta que lo acepte allí.

  2. Configure sus valores predeterminados

    El recorrido inicial ofrece orientación sobre cómo añadir un marcador y luego permite elegir Set up Defaults & Your Details (Configurar valores predeterminados y sus datos) o pasar directamente a Contactos. La configuración incluye un país, estado o provincia y ciudad predeterminados. Su nombre y otros datos son opcionales; puede añadir Ciudades (Cities), Regiones (Regions) y Áreas (Areas) ahora o más adelante.

  3. Añada su primer contacto

    Cuando termine la configuración, vaya a Contactos y añada un contacto cuando esté listo. Más adelante puede cambiar los valores predeterminados y sus datos en Settings (Configuración).

Antes de cambiar o restablecer

Haga una copia de seguridad antes de cambiar de copia

Antes de borrar los datos del navegador, quitar o reinstalar un icono o cambiar de dispositivo, cree una copia de seguridad actual y guarde otra copia por separado. Restáurela en la copia de NRV que quiera usar y compruebe que estén sus contactos antes de eliminar los originales. Al restaurar una copia de seguridad completa se reemplazan los contactos y la configuración de la copia de destino; no se combinan copias distintas. Consulte las instrucciones de copia de seguridad de la aplicación para obtener más información.

Los datos de trabajo se guardan en la copia del navegador o de la aplicación instalada que use. Las copias de seguridad opcionales de Dropbox, las exportaciones y el uso compartido pueden colocar datos en otros lugares. Algunas funciones de mapas y direcciones usan servicios externos; por ejemplo, al elegir una búsqueda de dirección, el texto de ubicación introducido se envía a OpenStreetMap Nominatim. Consulte la página de Privacidad del sitio web para obtener más información.
